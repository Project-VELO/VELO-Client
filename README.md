# velo
프로젝트 velo의 클라이언트 레포지토리입니다. <br/>
버전 정보 : Unity 6.3 LTS (6000.3.17f1)

## Tools

### 깨진 에셋 참조 검사

```
python Tools/scan_broken_refs.py
```

프리팹이나 에셋의 이름을 바꿀 때 `.meta`를 함께 옮기지 않으면 guid가 새로 생기고,
그것을 물고 있던 쪽은 없는 참조를 가리킨 채 남습니다. 유니티는 이를 조용히 건너뛰므로
**콘솔에 아무 경고 없이 화면 일부가 통째로 사라집니다.**

패키지 캐시까지 훑으므로 2~4분쯤 걸립니다.
깨진 참조가 있으면 종료 코드 1로 끝나므로 CI에 걸어 둘 수도 있습니다.

| 옵션 | 하는 일 |
|---|---|
| `--all` | `20. External Assets`까지 함께 검사합니다. 외부 에셋은 데모 리소스가 빠진 채 들어오는 일이 흔해 기본적으로 제외합니다 |
| `--no-ignore` | 무해한 것으로 등록해 둔 참조까지 함께 봅니다 |

무해한 것으로 확인된 참조는 스크립트 상단의 `IGNORED_GUIDS`에 이유와 함께 적어 두고
검사에서 뺍니다. 몇 건을 뺐는지는 실행할 때마다 표시되므로 목록이 낡으면 알아챌 수 있습니다.

### 프리팹 배치 오버라이드 검사

```
python Tools/scan_prefab_overrides.py
```

씬이나 상위 프리팹이 원본 프리팹의 배치를 덮어쓰는 곳을 찾습니다.
**프리팹을 고쳤는데 게임 화면이 안 바뀌면 대개 여기가 원인입니다.**

| 표시 | 뜻 |
|---|---|
| 값이 다름 | 인스턴스가 프리팹과 실제로 다르게 보이는 자리 |
| 값이 같음 | 아무 효과가 없는 오버라이드. 지우면 프리팹을 고쳤을 때 따라옵니다 |

| 옵션 | 하는 일 |
|---|---|
| `--all` | 값이 같은(효과 없는) 오버라이드까지 봅니다 |
| `--path` | 검사할 폴더나 파일을 지정합니다 |

중첩 프리팹은 한 단계씩 거슬러 올라가 실제로 이기는 값과 비교합니다.
프리팹 루트의 트랜스폼은 유니티가 늘 덮어쓰므로, 중간 층이 자리를 정해 둔 경우에만 봅니다.
